# 一个月复赛执行计划

## 当前进度

- 后端 Agent 状态图、安全分流、工具轨迹、短期会话与家长确认长期记忆已完成并有自动化测试。
- HarmonyOS 儿童输入、离线语音识别、逐页 TTS、家长建议和长期记忆管理源码已完成，HAP 可构建。
- 百炼结构化输出联调按团队决定暂缓；当前优先完成签名、真机、公网 HTTPS 和端到端稳定性。
- “源码已完成”不等于“真机已验证”，语音、朗读和网络异常仍需在目标设备逐项验收。

截止目标不是堆功能，而是形成一条真机可演示、状态可解释、结果可评测的儿童情绪陪伴 Agent 闭环。

## 第一周：Agent 基线和客户端骨架

负责人建议：B 主责，A 联调，C 编写案例。

- 完成 Agent 状态图、显式 mock 模式和百炼适配器骨架。
- 将固定回归集扩充到不少于 40 条，覆盖追问、绘本、关注和紧急介入。
- 启动 PostgreSQL，验证服务重启后会话状态和家长确认记忆仍存在。
- 统一公网 HTTPS 域名和 API 令牌配置。

验收：后端回归通过，mock 与真实模型模式边界明确；服务重启后记忆可读取。

## 第二周：HarmonyOS 真机主链路

负责人建议：A 主责，B 提供接口，C 做儿童交互检查。

- 接入 `CoreSpeechKit` 离线中文语音识别和麦克风权限状态。
- 接入 HarmonyOS TTS 或确认可用的官方朗读能力。
- 完成儿童输入、Agent 追问、绘本阅读和家长建议页面。
- 完成长时请求、断网、超时、百炼失败和权限拒绝状态。
- 加入家长确认、查看和删除记忆的界面。

验收：真机从说话到结果展示完整跑通 10 次；拒绝麦克风权限时仍可用文字完成流程。

百炼真实调用和 JSON 校验移到真机主链路稳定之后进行，仍需在冻结功能前完成连续案例验收。

## 第三周：主动服务和作品完成度

负责人建议：A、B 联合，C 主导演示设计。

- 增加经家长授权的次日回访工具，Agent 可创建一次性回访任务。
- 根据已确认记忆生成低压力回访问题，不自动推断或诊断。
- 完成绘本视觉素材与故事页朗读同步。
- 加入家长端的风险提示、记忆审批和回访管理。
- 记录每个状态节点和工具调用，形成可视化演示数据。

验收：至少演示“首次讲述 -> 家长确认 -> 次日回访 -> 根据反馈调整”的跨时间闭环。

## 第四周：评测和复赛材料

负责人建议：C 主责材料，A、B 冻结功能并修复问题。

- 冻结功能，只处理阻塞缺陷和表达问题。
- 完成不少于 100 条测试集，统计动作选择、结构化输出、风险召回和延迟。
- 真机录制 5 分钟以内演示视频，保留一条稳定主线和一条风险分流。
- 完成 800 字以内作品说明、架构图、设计稿、源码包和部署说明。
- 使用干净环境重新构建后端和签名 HAP，检查压缩包命名与材料完整性。

验收：三名成员都能在不看代码的情况下解释 Agent 状态、工具、记忆、安全和鸿蒙能力。

## 三人协作规则

- A 负责 HarmonyOS 客户端、语音、TTS、权限和真机。
- B 负责 Agent、百炼、数据库、安全、评测脚本和部署。
- C 负责交互、素材、测试案例、用户试用、文档和视频。
- OpenAPI 是前后端唯一接口依据；接口变更必须同步测试和 ArkTS 模型。
- 每两天跑一次完整真机主链路，每周末保存一次可演示版本。

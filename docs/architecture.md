# 童心驿站复赛版架构

## 产品边界

目标用户为 3-8 岁儿童及其监护人。系统处理日常情绪表达与亲子共读，不进行心理诊断、医疗建议或无人监管的危机干预。

复赛核心闭环：

```text
儿童语音/文字
  -> 安全规则筛查
  -> 事件与情绪结构化理解
  -> Agent 决策
      -> 信息不足：温和追问
      -> 日常情绪：调用绘本工具和家长建议工具
      -> 紧急风险：停止生成并请求监护人介入
  -> 保存本轮状态和可审计工具轨迹
  -> HarmonyOS 端展示与朗读
```

## 为什么这是 Agent

系统不是把输入直接拼成一个 Prompt。它维护会话状态，先理解环境，再根据状态选择动作和工具；不同风险和信息完整度会走不同路径，执行结果可通过 `tool_trace` 检查。

当前状态图节点：

- `safety_screen`：本地确定性安全筛查，不依赖模型。
- `understand_context`：百炼结构化提取事件、情绪、事实与缺失信息。
- `decide`：根据风险、置信度和缺失信息选择下一步。
- `ask_child`：只问一个低压力问题。
- `create_story`：生成三页陪伴绘本和插画描述。
- `parent_guidance`：生成家长回应、共读问题和行动建议。
- `guardian_escalation`：停止普通内容生成，请求可信成人介入。

## 模型模式

- `mock`：开发和测试专用；结果明确标注，不允许冒充在线模型输出。
- `bailian`：通过百炼 OpenAI 兼容接口调用千问；失败直接返回错误，由客户端提示重试，不静默降级。

## 一个月范围

### 必须完成

- HarmonyOS 原生儿童端主流程。
- `CoreSpeechKit` 离线中文语音识别。
- 百炼模型接入和 JSON 结构化输出校验（当前按团队决定暂缓，真机主链路之后恢复）。
- 多轮会话、短期记忆和家长确认后的长期记忆。
- 安全分级、家长介入和隐私删除能力。
- 固定评测集、工具轨迹、延迟与成功率记录。
- 公网 HTTPS 部署、真机演示和断网/失败状态。

### 可延后

- 实时文生图。
- 完整家长社区或内容平台。
- 心理量表、诊断或治疗建议。
- 多角色自由自治和无限工具循环。

## 三人初始分工

- A：HarmonyOS 客户端、语音、朗读、真机联调。
- B：FastAPI、LangGraph、百炼、存储、安全与部署。
- C：产品交互、绘本素材、测试集、作品说明和演示视频。

每两天进行一次主链路联调，接口契约由 OpenAPI 文档作为唯一依据。
